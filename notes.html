LM 01 · LARGE MODELS ONGOING

Deployment

Serving is the layer that turns a model into a product, and the layer most easily fooled by benchmarks. I care about the real cost structure of one model across serving stacks, batching strategies and precision settings: throughput goes up, so where do tail latency and peak memory go?

CURRENT FOCUS

Turning a benchmark table into a bill: cost per token, P99 latency and peak memory, read together or not at all.

  • At what load does the batching-versus-tail-latency trade-off flip sign?
  • Is the throughput bought with quantisation worth the accuracy it costs?
  • Should the KV-cache memory budget be accounted per request or per tenant?

LM 02 · LARGE MODELS ONGOING

Post-training

From SFT to preference alignment to RL, every stage filters data and every stage introduces bias. I care about the survival rate of gains: on a model one size smaller, how much improvement is real and how much is memorising the eval set?

CURRENT FOCUS

Reproduce before improving: get one full post-training chain running at small scale, then ablate it stage by stage.

  • Which data-selection metric actually predicts downstream gain?
  • What observable signals reveal that an eval set has been contaminated?
  • At what model size do RL-stage gains start to appear?

LM 03 · LARGE MODELS MAIN LINE

New attention architecture — Loop Attention

Reusing one attention block across depth keeps parameters flat while every layer sees more and more like the last one. The core question is simple: can the memory and compute saved buy back equivalent expressive power?

CURRENT FOCUS

First comparison run against a stacked baseline — memory, wall-clock and training stability, at small and medium scale first.

  • Where is the trade-off point between depth reuse and width scaling?
  • Which metric detects the representation collapse caused by reuse, early?
  • On long-context tasks, could reuse turn from cost into advantage?

AG 01 · AGENTS ONGOING

Building agents

Loop, memory and planning, taken as the smallest useful combination. A tool-less agent is the cleanest object of study: every failure comes from itself rather than from tools or environment noise. Understand it before adding anything.

CURRENT FOCUS

Build a taxonomy of tool-less agent failures first, then decide whether to add loop, memory or planning.

  • Which failure modes can extra tools fix, and which can they not?
  • Who should decide when a memory gets written?
  • At what task length does planning start to pay for itself?

AG 02 · AGENTS ONGOING

Tool design

A tool is an interface for the model first and for people second. Ambiguity in the schema, roughness of the error surface and the shape of the return value all convert directly into the model’s error rate.

CURRENT FOCUS

Redo schemas and error handling for a batch of real tasks, comparing failure distributions before and after on the same task set.

  • How detailed must an error message be before the model actually changes behaviour?
  • Is it better for tools to be coarse-grained or fine-grained?
  • How structured should a return value be?

AG 03 · AGENTS ONGOING

Multi-agent collaboration

Roles, routing and the cost of coordination. I am suspicious of multi-agent setups by default: for most tasks, one agent with good tools is cheaper and easier to debug. This line has to prove that coordination pays, not that more roles exist.

CURRENT FOCUS

Build a strong single-agent baseline first, then find the tasks where a multi-agent setup beats it reliably.

  • How does coordination overhead grow with the number of roles?
  • What signal says roles should be merged rather than split further?
  • How does failure propagate between roles?
NOTES IN PROGRESS
AG 04 · AGENTS ONGOING

RAG

Chunking, retrieval quality and answers that can be held to a source. Force a model to cite and weak links on both the retrieval and generation side stop hiding — which is why the evaluation set has to demand citations too.

CURRENT FOCUS

A citation-required QA set plus a scoring script: an answer must land on a specific passage, or it counts as wrong.

  • In what range is the chunk-size versus recall relationship most stable?
  • Should a wrong citation cost more than no citation at all?
  • At what corpus size does re-ranking start to pay off?

PH 01 · PHYSICS ONGOING

Light-front quantization

A hadron as a set of modes on the light front: kinematics turn multiplicative, the vacuum gets simple, and the Fock-space truncation becomes the one approximation you have to justify. This line is about where that truncation can be trusted.

CURRENT FOCUS

At fixed N, how far the light-front wave function can be pushed, and which observables barely notice N.

  • In which calculations does the multiplicative light-front kinematics actually save work?
  • If the vacuum got simpler, which physics got moved into the wave function instead?
  • Which observable is the right monitor for truncation error?
NOTES IN PROGRESS
PH 02 · PHYSICS ONGOING

Baryon light-cone Fock expansion

Baryon wave functions in the light-cone Fock basis — from three to five constituents, where the expansion coefficients are the wave function. The questions are convergence, and which observables survive a cut at fixed N.

CURRENT FOCUS

Get the three-quark sector clean first, then measure how much the five-quark sector moves the structure function.

  • Is convergence driven by transverse momentum or by the number of Fock components?
  • Which observables are least sensitive to the truncation?
  • In which process do five-quark components finally become visible?
NOTES IN PROGRESS
PH 03 · PHYSICS ONGOING

Proton structure — DIS / SIDIS / DY

DIS, SIDIS and DY are three windows on the proton: DIS for the collinear PDF, SIDIS for transverse momentum, DY for the same family from the other side. Put them in one picture and the 3D distribution of partons starts to hold still.

CURRENT FOCUS

Put the constraints from all three processes into one parameterisation, and start by finding where they disagree.

  • How much do the three processes disagree on the same ⟨k⊥²⟩?
  • In which Q² range does the Gaussian width model start to fail?
  • Which term of the 3D distribution is shortest on data?
