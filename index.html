Research

Two halves of one problem, plus the ground they stand on: the model itself, the agent that has to use it, and the physics the habits come from.

Large models
LM 01

Deployment

Serving, quantisation and the economics of the KV cache — what a token really costs across serving stacks, batching strategies and precision settings. I care about turning a benchmark into a bill.

SERVING · QUANTISATION · TAIL LATENCY
LM 02

Post-training

The SFT → preference → RL chain: how data gets selected, where evaluation should bite, and how much of a gain survives on a model one size smaller. Reproduction before leaderboard.

SFT · PREFERENCE · EVALUATION
LM 03

New attention architecture — Loop Attention

Reusing one attention block across depth: what it costs in memory, compute and stability, and where it genuinely beats a plain stack. I write the implementation and the ablations.

ARCHITECTURE · DEPTH REUSE · ABLATION
Agents
AG 01

Building agents

The smallest useful combination of loop, memory and planning. The starting point is plain: understand how an agent fails when it has no tools, then decide what to add.

LOOP · MEMORY · FAILURE ANALYSIS
AG 02

Tool design

Tools are read by models first and people second: schemas, error surfaces and return shapes, designed so the model stops doing stupid things and recovers when it does.

SCHEMA · ERROR SURFACE · API
AG 03

Multi-agent collaboration

Roles, routing and the cost of coordination. I am suspicious of multi-agent setups by default: for most tasks one agent with good tools is cheaper and easier to debug. Prove the coordination pays first.

ROLES · ROUTING · COST
AG 04

RAG

Chunking, retrieval quality and answers that can be held to a source. Force a model to cite and the weak links stop hiding — so the evaluation set has to demand citations too.

RETRIEVAL · CITATION · EVAL SET
Physics
PH 01

Light-front quantization

A hadron as a set of modes on the light front: kinematics turn multiplicative, the vacuum gets simple, and the Fock-space truncation becomes the one approximation you have to justify. This line is about where that truncation can be trusted.

LIGHT-FRONT · FOCK SPACE · TRUNCATION
PH 02

Baryon light-cone Fock expansion

Baryon wave functions in the light-cone Fock basis — from three to five constituents, where the expansion coefficients are the wave function. The questions are convergence, and which observables survive a cut at fixed N.

WAVE FUNCTIONS · CONVERGENCE · TRUNCATION
PH 03

Proton structure — DIS / SIDIS / DY

Three processes, three windows on the proton: DIS for the collinear PDF, SIDIS for transverse momentum, DY for the same family from the other side. Put them in one picture and the 3D distribution of partons starts to hold still.

PDF · TMD · 3D DISTRIBUTIONS
